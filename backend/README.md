# Papers Site Upload Backend

FastAPI backend for the private PDF upload and translation workflow.

## Environment

```bash
export LLM_API_KEY='...'
export LLM_BASE_URL='https://dashscope.aliyuncs.com/compatible-mode/v1'
export LLM_MODEL='gemini-3.1-pro'
export PAPERS_UPLOAD_PASSWORD='eden'
export PAPERS_SITE_REPO='/data/hilbert.xiong/papers-site'
export PAPERS_SITE_PUBLIC_URL='https://zijixie.github.io/papers-site'
export PAPERS_SITE_CORS_ORIGINS='https://zijixie.github.io,http://localhost:8000,http://127.0.0.1:8000'
```

Optional:

```bash
export GITHUB_TOKEN='...'
export PAPERS_SITE_METRICS_JSON='/data/hilbert.xiong/papers-site/backend/metrics.json'
export PAPERS_SITE_GIT_PUSH='1'
```

`PAPERS_SITE_METRICS_JSON` is the only source used for Q rankings, top-percentile text, and core-journal labels. If no trusted metric record exists, the generated page says the ranking is not verified.

## Run

```bash
cd /data/hilbert.xiong/papers-site
./backend/start_backend.sh
```

Expose with Cloudflare Tunnel, then put the public HTTPS URL into `upload-config.js`:

```bash
./backend/start_tunnel.sh
```

```js
window.PAPERS_UPLOAD_API = "https://your-tunnel.example.com";
```

Commit and push the changed static files:

```bash
git add upload.html upload-config.js styles.css backend .gitignore
git commit -m "Add private PDF upload translation workflow"
git push origin main
```

## GitHub Pages deployment

The backend creates `paperXX.html`, stores the uploaded original PDF under `assets/papers/paperXX/original.pdf`, updates `index.html`, commits the result, and only pushes when:

```bash
export PAPERS_SITE_GIT_PUSH=1
```

If `GITHUB_TOKEN` is set, the backend uses it through `GIT_ASKPASS` so the token is not written into the git remote URL or command line. If `GITHUB_TOKEN` is not set, the machine must already have GitHub write credentials configured. Do not put GitHub tokens in this repository or in `upload.html`.

## Truthfulness policy

The backend verifies DOI/title/venue/year with Crossref when possible. Journal or conference status claims such as Q1, top percentile, impact factor, CORE, SCI/SSCI, CSSCI, CSCD, or "核心期刊" are never generated by the LLM. They are emitted only when a trusted record exists in `backend/metrics.json`; otherwise the page says `期刊/会议分区与排名未核验`.
